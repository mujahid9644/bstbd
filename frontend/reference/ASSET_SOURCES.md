# Asset Sources

Assets already used locally for the first implementation originate from Unsplash and are licensed under the Unsplash License. Production use requires confirming that each selected image is suitable for the displayed subject and retaining source attribution where appropriate.

See the existing project asset record: `ASSET_SOURCES.md` in the workspace root.

Newly sourced assets must be added to this file with:
- Original URL
- Photographer/provider
- License URL
- Local filename
- Intended page/section
